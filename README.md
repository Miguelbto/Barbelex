# Barbelex
This is a project about microsomativa from Marlon

💈 Barbelex — Landing Page
Landing page moderna e responsiva desenvolvida para a Barbelex, uma barbearia de alto padrão. O projeto combina visual Dark Mode elegante com acentos em dourado, garantindo uma navegação intuitiva e focada na conversão de agendamentos.

 Funcionalidades
Hero Section Impactante: Imagem de fundo com overlay escuro, selo de avaliação do Google (+1.200 clientes) e chamada para ação (CTA).

Navegação Responsiva: Header com menu expansível (hambúrguer) adaptado para dispositivos móveis.

Grid Dinâmico de Serviços: Estrutura preparada para renderização de serviços via JavaScript (#services-grid).

Suporte via Chat Flutuante: Botão fixo no canto inferior direito para acesso rápido ao atendimento.

Design System Exclusivo: Paleta de cores Dark, Gold e Support, com tipografias Bebas Neue e Inter.
